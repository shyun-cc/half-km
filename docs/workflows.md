# 配送与团购操作流程

## 运营准备

1. 创建社区、楼栋和服务圈，把支持配送的楼栋加入对应服务圈的白名单。
2. 建立商户。商户选择服务圈并登记门店的收款账号。团购还需设置自提点，并给指定团长开通该点的核销权限。
3. 商户维护商品、规格、可用库存和优惠券。优惠券按商品金额计算，运费单独计入订单。

## 即时配送

买家先选服务圈内的楼栋，再确认配送地址、商品和金额后下单。订单最多保留库存 15 分钟。收款确认后，商户接单、自行配送并登记送达。未付款订单取消或超时后释放库存。若付款在订单失效之后入账，请通过原渠道办理退款并登记结果。

## 社区团购

商户选择场次的自提点、团长、可售规格、配额和截团时间。买家付款入账时占用配额。到达截团时间后，系统汇总已成功占用配额的订单并生成该自提点的分拣清单。零笔已付也会截团。

商户按清单分拣并登记到点。买家出示订单提货码，获授权的团长扫描核验，一笔订单只核销一次。配额已满或付款入账超过截团时间时，经原渠道退款后登记结果。

## 团长对账

核销完成满 7 天后，团长佣金可按已结束的期间结算。商品优惠和退款影响计佣金额。商户核对结算单，线下付款后登记金额、付款时间和凭证。退款冲减可进入后续结算期间。
