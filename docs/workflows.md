# 配送与团购操作流程

## 运营准备

1. 用运营令牌登录。在「社区与楼栋」创建社区、楼栋和服务圈，把支持配送的楼栋加入白名单。
2. 在「商户与团长」新建商户并启用服务圈；设置自提点，并授权对应团长。
3. 在「商品与库存」选择商户，配置商品、SKU、实物库存、可选优惠券和至少一个启用的收款渠道。价格以分填写。优惠券按商品金额计算，运费单独计入。
4. 根据商户和团长实际编号配置令牌，并为每个居民发放独立令牌。PC 与手机从同一站点入口登录。

## 即时配送

1. 居民在「附近商户」选择社区和服务圈，打开商户，选商品、白名单楼栋、收款渠道并填写详细地址。
2. 下单后在「我的订单」查看应付金额，按商户提供的方式付款并刷新状态。未付款的即时单最多保留库存 15 分钟，可取消。
3. 收款确认后，商户在「即时单履约」打开订单，依次确认接单、开始配送和确认送达。若款项在订单失效后入账，通过原渠道退款并由可信收款服务登记结果。

## 社区团购与核销

1. 商户在「团购与分拣」选择服务圈、自提点、授权团长、SKU 和付款配额，设置未来截团时间及佣金比例（100 基点等于 1%），发布场次。
2. 居民在「社区团购」选择场次、商品和收款渠道后提交订单。付款入账时占用配额。配额已满或付款入账超过截团时间时，通过原渠道退款并登记。
3. 到达截团时间后，「团购与分拣」生成该自提点的清单，零笔已付也会截团。刷新查看结果。商户按清单分拣，送到自提点后点击「登记到点」。
4. 居民在「我的订单」刷新团购订单并显示提货码。团长在「分拣单」查看 SKU 汇总与入批订单，在「提货核销」打开摄像头扫二维码，或选择自提点并手输订单号和提货码。核对信息后点击「确认核销」。每笔订单只核销一次。

## 团长对账

核销满 7 天后，佣金进入可结算范围。团长在「佣金明细」查看可结算时间、流水和付款状态。商户在「佣金结算」选择团长和已结束的 UTC 期间生成结算单。结束日不包含在期间内。线下付款完成后，打开结算单的「登记付款」并录入真实付款时间与凭证。退款冲减会进入可适用的后续期间。

## 在隔离实例试用收款登记

使用合成数据、单独的数据库和专用 `payments` 令牌。记录订单号、下单时选用的收款渠道编号（PC「商品与库存」中的编号）和实付整数分。由试用人员在终端登记一次模拟收款。将以下变量设为试用订单的值，`TEST_TRANSACTION_ID` 为该笔模拟付款唯一的流水号。

```sh
curl -fsS -X POST "http://127.0.0.1:8080/v1/orders/${ORDER_ID}/payment" \
  -H "Authorization: Bearer ${PAYMENTS_TOKEN}" \
  -H "Content-Type: application/json" \
  -d "{\"receiving_account_id\":${ACCOUNT_ID},\"transaction_id\":\"${TEST_TRANSACTION_ID}\",\"amount_cents\":${AMOUNT_CENTS},\"paid_at\":\"$(date -u +%Y-%m-%dT%H:%M:%SZ)\"}"
```

成功响应中 `data.disposition` 为 `accepted` 时，刷新订单继续履约。试用结算可使用隔离实例中已过售后期的测试订单。实际部署的收款与退款登记由商户接入的可信服务提交已验证的渠道结果。
